# Ticket 101 - Shared update for app and deployment

## Goal
Improve collaboration between development and operations.

## Developer tasks
- Update the application message
- Keep the health endpoint working

## Operations tasks
- Review Dockerfile
- Review deployment file
- Confirm the application port matches deployment settings

## Shared responsibilities
- Validate the app starts correctly
- Validate health check works
- Review changes before merge
- Use one workflow instead of blame
