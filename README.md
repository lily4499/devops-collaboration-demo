# DevOps Collaboration Demo

## Problem
Developers and operations do not work well together.
Communication is weak, work is separated, and blame happens when deployment fails.

## Solution
Use shared workflows, Git process, tickets, and shared responsibility.

## Project content
- app/ contains application code
- Dockerfile packages the app
- deploy/ contains deployment config
- docs/ contains ticket and runbook
- .github/workflows/ contains CI pipeline
